**Aluno:** [Leonardo Ávila Ferreira Silva]


## Descrição
Aplicação web simples em Node.js e Express com três telas: Home, Lista de itens e Formulário de criação. A comunicação com uma API externa é mockada localmente (arquivo `mock_data.json`).


## Instalação


1. `git clone <seu-repo-url>`
2. `cd nodejs-webapp`
3. `npm install`


## Execução


- Iniciar servidor: `npm start` (acessa em http://localhost:3000)
- Em desenvolvimento: `npm run dev`


## Testes


- Executar todos os testes com cobertura: `npm test`
- Executar apenas unitários: `npm run test:unit`
- Executar apenas integração: `npm run test:integration`
- Executar apenas aceitação: `npm run test:acceptance`
